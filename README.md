# 📊 Instagram User Usage Analysis Dashboard

> An interactive Power BI dashboard that analyzes Instagram user behavior, demographics, engagement, and advertising performance to generate actionable business insights.

---

## 📌 Project Overview

This project explores Instagram user data to better understand user demographics, engagement patterns, subscription behavior, and platform performance. Using **Power BI**, I transformed raw data into an interactive dashboard that helps stakeholders monitor key metrics and make data-driven decisions.

The project demonstrates the complete data analysis workflow, including:

* Data Cleaning & Transformation
* Data Modeling
* DAX Calculations
* Interactive Dashboard Design
* Business Insight Generation

---

## 🎯 Business Objective

Social media platforms collect massive amounts of user data every day. The objective of this project is to answer important business questions such as:

* Who are the platform's most active users?
* Which countries contribute the largest user base?
* What subscription plans are most popular?
* How are users distributed across demographics?
* How effective are advertisements?
* What trends exist in user engagement over time?

# 📈 Key Insights

### 👥 User Demographics

* The dataset contains approximately **247,000 users**.
* The average user age is **39 years**.
* Male and female users are almost equally represented.
* Most users are employed full-time.

---

### 🌍 Geographic Insights

* The **United States** has the highest number of users.
* India and Brazil follow as the second and third largest user bases.
* Australia, Canada, Germany, Japan, and South Korea contribute a smaller but valuable share of users.

---

### 💳 Subscription Insights

* Most users use the **Free** subscription plan.
* Premium users account for approximately **15%** of all users.
* Business subscriptions represent the smallest user segment.

---

### 📚 Education Insights

* Users with a Bachelor's degree form the largest educational group.
* PhD holders represent the smallest portion of users.

---

### 📢 Advertisement Performance

* Overall Advertisement CTR is approximately **24%**.
* Advertisement clicks closely follow advertisement views, indicating healthy user engagement with promotional content.

---

### 📅 User Growth

* User registrations remain relatively stable across the years.
* No significant decline in new account creation is observed.
